# SisGeral · apresentação

Apresentação do SisGeral, gerenciador de atendimento de SAC num arquivo HTML, escrita pra gestão: o que é, como funciona, o que respeita, o que deu e o que seria preciso pra levar ao time.

**Ler online:** [mmbrosium.github.io/apresentacao-sisgeral](https://mmbrosium.github.io/apresentacao-sisgeral/)

**Testar o sistema (homologação):** [abrir o SisGeral](https://mmbrosium.github.io/apresentacao-sisgeral/sisgeral/)

**Portfólio completo:** [mmbrosium.github.io](https://mmbrosium.github.io/)

**Ler no computador:** baixe o repositório (Code > Download ZIP), descompacte e abra `index.html`. Não precisa de internet.

A pasta `sisgeral/` traz uma versão de **homologação** do sistema (catálogo reduzido, ABC sem códigos, VDN com números de referência), pra testar ao vivo. A versão completa fica em repositório privado: [mmbrosium/sisgeral](https://github.com/mmbrosium/sisgeral).
